Firmamento Tienda Online con Django

Aplicación web de comercio electrónico. Una tienda online completa de camisetas con funcionalidades avanzadas, desarrollada con Django, PostgreSQL y desplegada con Docker.

Django Python PostgreSQL Docker HTML/CSS JavaScript
Ver en GitHub Ver capturas

Funcionalidades Principales

Gestión de Usuarios

Sistema completo de registro, login y perfiles de usuario con validaciones robustas y correos de bienvenida automáticos.

Carrito Inteligente

Carrito persistente para usuarios registrados y temporal para anónimos, con transferencia automática al iniciar sesión.

Pedidos y Facturas

Proceso completo de checkout con generación automática de facturas en PDF y envío por email de confirmación.

Historial de Compras

Los usuarios pueden consultar todos sus pedidos anteriores con detalles completos de cada compra realizada.

Sistema de Contacto

Formulario funcional que envía emails tanto a los administradores como confirmación al cliente.

Diseño Responsive

Interfaz moderna en tema oscuro, completamente adaptable a dispositivos móviles y desktop.

Capturas del Proyecto

Sistema de Autenticación

Página de login con validaciones y diseño moderno en tema oscuro.

Tienda Principal

Catálogo de productos con filtros, carrito y navegación intuitiva.

Panel de Administración

Gestión completa de productos, pedidos y usuarios desde Django Admin.

Desafíos Superados

Despliegue con Docker

Configuración completa del entorno de producción con Docker Compose, PostgreSQL y gestión de variables de entorno.

Generación de PDFs

Implementación de facturas automáticas en PDF usando WeasyPrint, incluyendo la resolución de dependencias del sistema.

Trabajo en Equipo

Colaboración efectiva usando Git, manejo de ramas por funcionalidad y resolución de conflictos en equipo.
